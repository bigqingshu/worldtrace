# 早期目录规划记录

> 本文是讨论过程中的历史记录，其中路径示例和部分预建目录已经被后续决定取代。当前有效规则见[目录与模块边界规则](../../architecture/目录与模块边界规则.md)和[项目中文导航](../../../README.zh-CN.md)。

建议采用“两层目录”：工作区负责容纳外部仓库、环境和大文件；`worldtrace`只保存自己的源码与可版本化内容。不要把虚拟环境、模型权重、录屏数据和其他Git仓库塞进主仓库。

## 工作区

推荐根目录：

```text
D:\Games\nikkigallery\worldtrace_workspace\
```

```text
worldtrace_workspace/
├── worldtrace/             # 主项目Git仓库
├── reference_repos/        # 原样拉取的Whimbox、ALAS等开源项目
├── reference_forks/        # 确实需要修改的外部项目分支
├── environments/           # 实际Python虚拟环境
├── model_store/            # OCR、YOLO、CLIP、SAM权重
├── data_store/             # 录屏、输入轨迹、标注集和回放数据
├── runtime_data/           # 运行日志、证据包、数据库和缓存
└── scratch/                # 临时验证、一次性脚本和实验输出
```

各区域用途：

| 文件夹 | 内容 | 是否进入主项目Git |
| --- | --- | --- |
| `reference_repos` | 未修改的开源参考项目 | 各自维护自己的Git |
| `reference_forks` | 需要打补丁或做对照实验的外部源码 | 独立Git |
| `environments` | Python 3.12虚拟环境 | 否 |
| `model_store` | 模型权重和下载缓存 | 否 |
| `data_store` | 截图、视频、标注和回放样本 | 否 |
| `runtime_data` | 运行证据、日志、SQLite、临时缓存 | 否 |
| `scratch` | 不稳定实验 | 否 |

### `docs`：文档区

```text
docs/
├── 00-项目总览/
├── 01-架构与协议/
├── 02-项目构想/

```

当前Whimbox里的构想文档以后可以迁入`02-项目构想`；Whimbox、ALAS和UIAgent分析放入`03-参考项目分析`。

### `src/worldtrace`：核心源码区

```text
src/worldtrace/
├── core/                   # 公共类型、ID、时钟、生命周期
├── capture/                # 连续帧采集与FrameStream
├── timeline/               # 帧、输入、窗口事件时间对齐
├── perception/             # OCR、YOLO、CLIP、SAM适配
├── state/                  # StateSnapshot和状态解释
├── spatial/                # MapSpace、定位和空间拓扑
├── graph/                  # StateDefinition、TransitionDefinition
├── planning/               # AbstractPlan与PlanCompiler
├── control/                # 视角、移动、滚轮等控制器
├── runtime/                # PlanRun、CapabilityRun、StepAttempt
├── evidence/               # EvidenceBundle和证据存储
├── recovery/               # 看门狗、归因与RecoveryRun
├── adapters/               # 游戏、平台和模型Adapter
└── api/                    # 对前端、CLI和外部服务接口
```

### `services`：独立进程区

```text
services/
├── coordinator/            # 总调度与运行控制
├── capture_worker/         # 截图服务
├── input_worker/           # 键鼠记录和执行
├── vision_worker/          # YOLO、CLIP、SAM
└── ocr_worker/             # OCR独立服务
```

使用同一Python 3.12大版本，不代表所有依赖必须安装在一个虚拟环境。Paddle、Torch和协调器仍建议分环境、分进程运行。

### `apps`：用户工具区

```text
apps/
├── cli/                    # 命令行工具
├── desktop/                # 桌面前端
└── replay_inspector/       # 帧、输入和证据回放分析器
```

`replay_inspector`非常重要，基础模块调试不能完全依赖实时启动游戏。

### `profiles`：游戏适配区

```text
profiles/
├── games/                  # 每个游戏的窗口、UI和控制Profile
├── models/                 # 模型选择、阈值和设备档位
├── devices/                # GPU、显示器、DPI和输入设备
└── risks/                  # 自动确认、禁止操作和重试策略
```

游戏专用模板和规则不要散落在核心源码中。

### 其他必要区域

| 文件夹 | 职责 |
| --- | --- |
| `configs` | 开发、测试、回放和正式运行配置 |
| `schemas` | Frame、Evidence、Attempt、事件等跨进程协议 |
| `assets` | 小型模板、遮罩、标签定义和测试素材 |
| `tests` | 单元、集成、回放、故障注入和契约测试 |
| `experiments` | 新识别器和控制算法的受控实验 |
| `benchmarks` | 延迟、显存、准确率、停止距离等基准 |
| `tools` | 数据采集、标注、转换和诊断工具 |
| `environment_specs` | 环境锁定文件，不保存真实虚拟环境 |
| `migrations` | 数据库和Schema迁移 |
| `deploy` | 本地服务启动、打包和部署配置 |
| `third_party` | 外部代码、模型和数据集的许可、哈希及补丁记录 |
